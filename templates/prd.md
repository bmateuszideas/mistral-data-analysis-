# Template: product requirements document (PRD)

Used by: `workflows/transcript-to-prd.md`, `prompts/tasks/generate-prd.md`

```markdown
# PRD: <title>

## Purpose
<why this product/feature exists, in 2-3 sentences>

## Scope
<what is in scope and what is explicitly out of scope>

## Features and requirements
- <feature or requirement, numbered>

## User personas
- <persona>: <needs and goals>

## Technical requirements
- <technical constraint or requirement>

## Constraints
- <budget, time, platform, or compliance constraint>

## Success metrics
- <measurable metric and target>

## Timeline and milestones
- <milestone> — <date or phase>
```

Rules: include only sections that have a source in the input (transcript, notes). Omit sections with no source. Never add information that is not present in the source material. Keep the source language.
